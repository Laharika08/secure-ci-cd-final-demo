# Pre hire demos
This repository is about pre-hire codes for our pre-hire engineers in weeks 4 & 5 of their program

##  what kind of automation is configured in the repository?
Currently, there's not any kind of an automation for the repository

## Rules & How to edit the repository?
You're not allowed to push your code in the main branch, instead 
- pull the code
- Make a folder with your name following this schema "first name - second name"
- Copy your project code in there
- Commit it to a new branch with a discriptive name as instructed in the pre-hire immersion document
- Create a Pull Request
